# O*NET job title data

`onet-computing-job-titles.json` is generated from the O*NET 30.3 database,
using occupation titles and reported job titles for O*NET-SOC occupations
whose codes begin with `15-` (Computer and Mathematical Occupations).

Source: [O*NET 30.3 Database](https://www.onetcenter.org/dl_files/database/db_30_3_text.zip)
